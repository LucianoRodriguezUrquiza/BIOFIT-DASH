# Biblioteca de recursos: guia para colaboradores

- El catalogo LOCAL completo se encuentra en `BIOFIT-RECURSOS-GD`, fuera del repositorio.
- Ejecutar `tools/assets/Preparar_Biblioteca_BIOFIT.ps1` solo en una maquina SIN la biblioteca, para descargar las fuentes.
- Ejecutar `tools/assets/Organizar_Catalogo_BIOFIT.ps1` para crear categorias, CSV e indice HTML local.
- Abrir `BIOFIT-RECURSOS-GD/03_CATALOGO/VISUAL/index.html` en el navegador.
- `docs/assets/RESUMEN_CATEGORIAS.csv` y `FUENTES_VERSIONES.csv` son los inventarios LIGEROS publicados.
- `INVENTARIO_COMPLETO.csv` e `INVENTARIO_CLASIFICADO.csv` quedan solo en la computadora; subir 194750 entradas a Git no es necesario.
- `02_COLECCIONES/*.csv` son vistas por categoria; NO contienen imagenes duplicadas.
- Los recursos de Geometry Dash son material de estudio: no se distribuyen en Git ni APK.
- Solo importar arte propio o assets con licencia verificada. Consultar `docs/ASSET_SOURCES.md`.
- No se cambia el firmware ni las fisicas ni el detector BILATERAL LEGACY.
