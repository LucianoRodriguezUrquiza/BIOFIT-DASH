# GeomeTry — aviso de licencia (componentes mecánicos adaptados)

Proyecto original: https://github.com/Christ0u/GeomeTry
Referencia de código: d922caddb4d21ecb791a266143e279bdb969d42c

Se adaptaron las ideas y partes de la lógica del cubo en Character.cs / Cube.cs:
movimiento automático, impulso vertical fijo y rotación durante el vuelo.
No se incorporaron los prefabs, texturas, audio, escenas, música, orbes,
nave, onda ni UI del proyecto original.
