## Alcance implementado
- Level Editor: catálogo izquierdo ancho 310, texto alineado a izquierda, salto de línea, tooltip, búsqueda y páginas de 60. El catálogo importado se carga desde Builds/BiofitV65Art/Catalog.json; preview local, no se incorpora el catálogo completo a Resources. Los sprites GD se copian bajo demanda cuando se coloca o valida un objeto, verificando exclusiones de Git sin modificar .gitignore.
- Vista real: elegir punto X/Y del mapa o usar centro de vista; Vista real guarda borrador, abre automáticamente el Main Menu original en Play Mode y carga la ranura, usando el constructor real de geometría, materiales, capas, contornos y tracks de color del runtime. Se detiene la simulación, se oculta el personaje y se libera la cámara de seguimiento. Flechas X/Y, rueda zoom, slider 0–100%, recorrer 0.25/0.5/1/2x, HUD y zoom original. El color se evalúa según la X de cámara, no se reproducen todos los efectos transitorios de una partida. Volver al editor sale de Play Mode y recupera borrador. Si no se abre Game View, seleccionar su pestaña; si el editor flotante tapa la ventana principal, minimizarlo. Exclusivo UNITY_EDITOR.
- Jugar desde aquí: usa el borrador, el motor real de Unity y la posición X/Y central en GD. Seleccionar Cube, Ball, Spider, Mini Cube, gravedad normal/invertida o Auto por portales (estimación a partir de los portales previos; no infiere acciones de inversión del jugador). Elegir punto en mapa y clic; marcador cian. Reiniciar aquí por muerte/recarga; Volver al editor termina Play Mode. No requiere aplicar Active ni recorrer desde inicio. No incluye invulnerabilidad: se busca comprobar colisiones reales. Evitar posiciones dentro de sólidos o pinchos. La prueba puede empezar en el aire; no pretende reconstruir el estado histórico completo de una partida previa.
- Red Pad: kind redPad, ID local reservado 900001, velocidad vertical inicial 9.5 u/s de simulación, opuesta a gravedad. Reutiliza bump_03 con tinte rojo; no requiere BLE/cooldown. Para Cube normal/invertido y mini. Altura ideal 1.15 bloques bajo g=39.24, alcance ideal 3.15 bloques con velocidad 6.5; Unity discreto y hitboxes exigen prueba real. No modificar valores amarillo 20, rosa 12.5, normal 13.5.
- Mini Cube: Clutterfunk (Resources/levels/11.txt del RAR GD 2.207) contiene cuatro portales ID 99 y cinco ID 101. Atlas GJ_GameSheet02-hd: portal_09 rosa mini y portal_08 verde tamaño normal. El archivo de nivel y las texturas NO determinan los parámetros físicos ejecutables originales. Se eligen provisionalmente escala 0.60, velocidad X 7.8 u/s, salto 10.5 u/s, gravedad magnitud 4, con soporte basado en hitbox reducida. Enum MiniCube/MiniInvertedCube, solo al atravesar portal de tamaño siendo Cube; mini portal y normalSizePortal restauran tamaño/gravedad correspondiente; cambiar de vehículo vuelve a tamaño normal. No se afirma fidelidad física a Geometry Dash. Cube normal mantiene original Character/Cube; Ball/Spider no cambian sus físicas. El mismo bridge BLE dirige acciones al motor para modo mini, sin tocar firmware, detector ni cooldown. Portales requieren importación local.
- Personalización: tabs CUBO, BOLA, SPIDER en pantalla original. 70 cubos anteriores conservados; selección Ball/Spider persistente independiente por PlayerPrefs, página 12, fallback procedural cuando no hay arte local. Spider usa siete poses de Spider_run_001–007 de Spider_AnimDesc.plist, composición de las seis piezas de cada skin (posición/escala/rotación/flip/z), paleta BIOFIT provisional y ciclo 14 fotogramas/s de simulación. Solo animación visual; no modifica colliders ni teletransporte. El importador usa recursos locales autorizados, no sube originales.
- Publicación selectiva: level_delta.py permite v6.5-desarrollo, conserva guardas de rama remota y hashes. Nunca recrea ramas eliminadas. Solo JSON e índice; no publicar imágenes originales. Deltas que referencien gd_* requieren que el otro entorno ejecute el importador y materialice los frames locales; no confundir delta con los archivos gráficos.
