## Uso
- Con ambos FW230, entrar Configuración > BMD, esperar versiones y CONSULTAR. La entrada BLE se bloquea si un FW230 no ha sido verificado o hay discrepancia; teclado/táctil no se modifican.
- Seleccionar bits 1/2/4/8; APLICAR AMBOS en reposo, sin RAW ni registro CSV. Esperar confirmación explícita de ambos perfiles/token (no basta ACK). Si uno falla, consultar y RESTAURAR 0; si persiste, reiniciar ambos trackers y reconectar. No jugar durante cambio. No se escribe NVS. 
- Volver a Configuración e INICIAR REGISTRO (RAW apagado). BMD sombra compara 80/90/100/110/120 mg con detectores independientes, igual cooldown y ventana; solo eventos UP frescos/reloj listo, no acciona personaje. Registra BMD_SHADOW por evento junto a seq/sensorMs; no es ground truth ni mide recall físico. Sombra reinicia al cambiar cooldown/ventana. 
- BMD INICIAR TRACE (ambos; puede hacerse con CSV activo y RAW OFF). Volver al juego, cuando falla regresar rápidamente a BMD y CONGELAR TRACE. Buffer circular ~4.6 s, puede perder primer fallo durante navegación; congelados secuencialmente, no sincronizados. Registrar vídeo/UP/AR. Finalizar CSV, luego DESCARGAR TRACE. Hasta 6144 peticiones CONFIG para 2 trackers completos, puede demorar; progreso/cancelación. No se transmiten durante juego. Cada página valida pie/generación/índice/esquema. Si falla, repetir descarga completa; trace congelado permanece en placas hasta nueva captura/reinicio. Se crea CSV separado con SHA256 solo después de leer ambas trazas; EXPORTAR TRACE usa exportador Android existente. Guardar también CSV de juego con DESCARGAS normal.
- Control concurrente: rawTransition común; ninguna operación BMD con RAW en curso o cierre/exportación; una solicitud por conexión; cancelación en pausa/desconexión; perfil permanece RAM si se desconecta. No hay transacción atómica entre trackers, se bloquean acciones BLE hasta confirmar ambos. Los tiempos de transición se registran; se invalidan pendientes y se descarta entrada durante operación + 250 ms. 
- Pruebas CI host: protocolo estricto, ACK/readback, páginas cruzadas, signed int, sombra independiente; regresiones existentes. CI no es compilación Unity/Android real ni prueba de GATT real. No declarar causa raíz ni validación física. Pendiente probar dispositivo, coste de miles de peticiones y sincronización de ambos trackers.

## RCA — revisión de exportación y captura
Se encontró que el verificador de archivos existente solo aceptaba 15 columnas; se amplía exclusivamente para el encabezado exacto BMD de 21 columnas, conservando el formato legado. Prueba real de cierre, SHA, corrupción y número de campos. Se agrega congelado desde pausa de nivel si el trace está armado; evita recorrer menús durante el corto buffer (no garantiza conservar el primer fallo si el usuario tarda). Se mantiene bloqueo de reanudación durante operación. Resumen de sombra añadido al CSV final.
